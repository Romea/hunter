# hunter_hardware

## 1) Overview

`hunter_hardware` provides the live `ros2_control` hardware plugin for the Hunter mobile base.

It specializes the generic `1FAS2RWD` hardware abstraction from `romea_mobile_base_hardware` and connects it to the Hunter low-level controller through the AGX CAN interface.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `hunter_hardware/HunterHardware` | `HardwareSystemInterface<HardwareInterface1FAS2RWD>` | `1FAS2RWD` |

## 2) Hardware concept

`HunterHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `hunter_description`.

At runtime, it:

1. reads the Hunter `ros2_control` hardware information;
2. creates the `HardwareInterface1FAS2RWD` command and state interface mapping;
3. loads the rear wheel radius used to convert wheel angular speeds;
4. connects to the Hunter low-level controller on `can0`;
5. enables commanded mode;
6. converts controller-side rear wheel speed commands into a longitudinal speed command;
7. sends longitudinal speed and front axle steering commands to the robot;
8. exposes front steering and rear wheel speed feedback through `ros2_control` state interfaces.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController1FAS2RWD` writes front axle steering and rear wheel speed commands, then reads the corresponding feedback from state interfaces to compute odometry.

The command path is implemented. The low-level actuator feedback decoding is still incomplete in the current hardware implementation and must be finished before relying on live odometry feedback.

## 3) CAN communication

The current implementation uses the AGX robotics SDK over SocketCAN on:

```text
can0
```

The hardware plugin sends:

* commanded-mode activation;
* longitudinal speed commands;
* front axle steering angle commands;
* null commands when the interface is connected or disconnected.

It is expected to receive:

* front axle steering angle feedback;
* rear left and rear right wheel speed feedback.

## 4) Relation with other packages

`hunter_hardware` is the live hardware specialization of the Hunter mobile base:

* `hunter_description` selects `hunter_hardware/HunterHardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `1FAS2RWD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `hunter_bringup` starts the controller manager and loads this hardware plugin in live mode.
